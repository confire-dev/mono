Confire is a context optimizer for AI coding agents. It runs as a background daemon and intercepts tool call responses **before they reach the model**, stripping noise to keep the context window lean.

## What it does

Every time Claude Code finishes a tool call — running a shell command, reading a file, fetching a URL — the raw output goes back to the model. Most of that output is noise: stack traces you don't need, boilerplate HTML, hundreds of lines of log you'd never read. Confire cuts it down to signal.

## How it works

```
Claude Code finishes a tool call
  → confire hook (PostToolUse, stdin: raw tool output)
  → daemon (Unix socket)
  → optimizer (local or remote)
  → stripped output back to Claude Code (stdout)
```
