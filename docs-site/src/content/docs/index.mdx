Confire is a context optimizer for AI coding agents. It runs as a background daemon and intercepts tool call responses **before they reach the model**, stripping noise to keep the context window lean and costs low.

## What it does

Every time your agent finishes a tool call — running a shell command, reading a file, fetching a URL, querying a design tool or a project manager — the raw output goes back to the model. Most of that output is noise: stack traces you don't need, boilerplate HTML, hundreds of lines of log, verbose JSON, component trees. Confire cuts it down to signal.

## How it works

```
Agent finishes a tool call
  → PostToolUse hook fires
  → confire hook receives raw output
  → daemon selects optimizer by tool type
  → stripped output returned to agent
```
