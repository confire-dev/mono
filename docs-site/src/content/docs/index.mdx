Confire is a local tool and context firewall for AI coding agents. It
sits beside your agent workflow and inspects tool activity before tools run and after they return.

---

## Tool Firewall

Runs before supported tool calls. Confire can allow, warn, review, or
block risky actions before they execute, including:

- destructive Git operations
- force pushes
- secret-file reads
- database resets
- deploys and package publishing
- mutating MCP actions

## Tool Result Firewall

Runs after supported tool calls. Confire inspects tool results and
returns firewall context back to the agent. This context can include:

- secret-looking value warnings
- prompt-injection warnings
- hidden Unicode warnings
- MCP risk notes
- provenance metadata
- policy decisions
- suggested next steps

Confire does not need to replace the original tool output to be useful.
It gives the agent and user additional security context around what
just happened.

## Works across supported clients

One install command.

- **Claude Code**: hook-based firewall mode
- **Cursor**: supported tool-event integration
- **VS Code**: supported tool-event integration
