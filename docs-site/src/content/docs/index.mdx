Confire is a context and tool firewall for AI coding agents. It
sits between your agent and the tools it runs, intercepting every
tool call in both directions — before it executes and after it
returns.

---

**Tool Firewall** — runs before each tool call. Reviews, warns, or
blocks risky commands: destructive git operations, mutating MCP
actions, secret file reads — before anything executes.

**Context Firewall** — runs after each tool call. Sanitizes MCP
output, redacts common secret patterns, strips hidden-unicode
injection attempts, and removes noise before output enters the
model context.

---

One install command. No proxy, no new MCP server.
