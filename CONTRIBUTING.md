# Contributing

Confire is currently proprietary software. This repository is not open for external contributions at this time, though that may change in the future.

## Found a bug or have a suggestion?

Reach out at **hi@confire.dev** or open a GitHub Issue with as much detail as possible:

- What you expected to happen
- What actually happened
- Your OS, shell, and editor/client (Claude Code, Cursor, VS Code)
- Output of `confire version` and `confire status`

## Security issues

Do not open a public issue for security vulnerabilities. See [SECURITY.md](SECURITY.md) for the responsible disclosure process.

## Internal contributors

If you have write access to this repo, follow the conventions in [`docs/internal/conventional-commits.md`](docs/internal/conventional-commits.md) for commit messages and the branch/PR workflow described in [`docs/internal/deploy.md`](docs/internal/deploy.md).
